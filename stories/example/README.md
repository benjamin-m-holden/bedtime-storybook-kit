# The Fox Who Could Not Sleep (example story)

A made-up six-page story used to prove the kit end to end. It is NOT a real recording: the audio
is generated, the words are deliberately plain, and the cast (Pip the fox, Moon the owl) is drawn
in `src/kit/example/`.

| File | What it is |
|---|---|
| `meta.json` | Title, told_by / told_to (blank placeholders), summary, cover seconds (`intro`), story length (`end`), closing seconds (`outro`), `caption_fixes`. |
| `pages.txt` | The page text, one sentence per line; `@12.3` pins a time. |
| `pages.json` | Generated by `tools/time_pages.py`: every sentence with its time. |
| `words.json` | Word timings. For a real story, `tools/transcribe.py` writes it; here `make_audio.py` does. |
| `transcript.txt` | The plain transcript. |
| `cues.json` | Moments where the room leaks into the telling (one listener question on page 3). |
| `moments.json` | Optional: the story time of the still used for each page of the flip book. |
| `BIBLE.md` | The tool-independent description of the book. |
| `make_audio.py` | Builds `public/example.m4a` (git-ignored), read aloud by Piper if you have it (see the main README), else espeak-ng, else a beep per sentence. Skip it when you have a real recording. |

For your own story, copy this folder, replace the files with your story's, and add a sheets file
like `src/sheets/ExampleBook.tsx` to `src/Root.tsx`.
